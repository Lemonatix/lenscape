Physik: dünne Linse in Näherung schwacher Felder, β = θ − θE²/θ (Punktmasse) bzw. β = θ − αSIE(θ) (elliptische isotherme Galaxie, Keeton 2001; für q = 1 ist |α| = θE) mit θE² = 4GM/c² · Dds/(DdDs). Ein langsameres c verstärkt die Ablenkung wie 1/c². Abstände euklidisch (Dds = Ds − Dd); die kosmologisch korrekte Rechnung steckt im Python-Teil von lenscape. Für sehr starke Felder (nahe am Schwarzen Loch) ist die Näherung nur qualitativ. Gerechnet wird pro Pixel auf der Grafikkarte (WebGL2). Zum Einbinden in andere Seiten: index.html?embed.
